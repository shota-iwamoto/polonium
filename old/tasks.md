## 2. 次の一手 — 第29章の残り（②〜④）

**目的**：`selfhost/` を v2 の規則に合わせ、**検査と解放を既定にする**。
これが終われば「自分自身を、自分の新しい安全規則でコンパイルできる」状態になります。

- [ ] **②** `selfhost/` の 222 件を片付ける
      - `str` のフィールド保存は `copy()` で直した（31 件。第26章）
      - 残りは**共有グラフ**（`ast.Node` / `token.Token` / `ast.Type` / `types.FuncSig`）。
        `rc[T]` にする型を選び、**1 つずつ**移行して毎回 `make bootstrap` で確認する
      - `E-BORROW-5`（5 件）と `E-BORROW-6`（5 件）は**本物の危険**なので個別に直す
- [ ] **③** `src/ownck.c` を `selfhost/ownck.po` に移植（第22〜24章ぶん）＋
      解放の挿入を `selfhost/codegen.po` に移植（第25章ぶん）
- [ ] **④** `--deny-*` と `--drop` を既定 on にし、`make bootstrap` が緑であることを確認
- [ ] `unsafe` / `ptr[T]` / `asm` の移植（第30章ぶん。`# STAGE1-SKIP:` を外す）
- [ ] **一時値の解放**（第25章の宿題）。Linux の CI が LeakSanitizer で検出できます:
      `make drop-leak`（macOS の ASan には LeakSanitizer が入っていないので、
      この宿題は Linux でしか測れません）

**⚠️ 順序を守ること**：②（既存コードを直す）→ ③（検査を移植する）。
逆にすると、移植した検査が自分自身に大量の警告を出して、
「移植が正しいか」の判定を邪魔します（第29章 §29.6）。

## 7. 第26章の宿題（検査が見つけた既存コードの違反）

**⚠️ この一覧は「消すために仕様を緩める」ためのものではありません。**
第26章で `selfhost/` を v2 の書き方に直すときの作業リストです。

| 章 | 検査 | `selfhost/` | `lib/` |
|---|---|---|---|
| ch22 | `E-MOVE-1`（移動済みの値の使用） | 108 | 0 |
| ch23 | `E-BORROW-3`（借用の保存） | 78 | 0 |
| ch23 | `E-BORROW-4`（借用の返却） | 34 | 0 |
| ch24 | `E-MUT-1`（読み取り専用への書き換え） | **0** ✅ | 0 |
| ch24 | `E-BORROW-5`（借用の衝突） | 4 | 0 |
| ch26 | `E-BORROW-6`（借用の寿命超過） | 4 | 0 |
| | **合計** | **228** | **0** ✅ |

**★ `E-MUT-1` は第26章で 0 件になりました。** `E-BORROW-5` の 4 件は
「`mut` を書いたから初めて見えた」ものです（第24章の予告どおり）。

**★ 残り 228 件はすべて「所有者を 1 つに決められない」と言っています。**
`rc[T]`（第28章）を入れてから、第29章で片付けます（決定 D20）。

`E-BORROW-5`（4 件）と `E-BORROW-6`（4 件）は**本物の危険**（同時可変・寿命超過）なので、
共有の問題とは別に、第29章で個別に直します。

**★ `E-MOVE-1` は第22章の 196 件から 138 件に減りました。** 借用を「移動として記録しない」
ようにしたので、同じ問題がより早い場所で 1 回だけ報告されるようになったためです。

`lib/` は第26章で移行済みです（`dict.set` は `k: own str`、
`strings.replace` は `s: own str`、呼び出し側は `copy(word)`）。

```bash
# 全部見る（既定は先頭 20 件で打ち切る）
clang -std=c11 -O0 -w -DOWNCK_MAX_REPORT=100000 ... src/*.c -o /tmp/plc-all
/tmp/plc-all selfhost/main.po -o /tmp/s1
```

いちばん多いのは「フィールドから取り出して、その後もオブジェクトを丸ごと使う」形
（`cached = elem.opt` の後に `elem` を使う）。直し方の候補は
[ownership.md §8](../docs/design/ownership.md) の表を参照。
