## なぜ消さずに残しているか

**設計の理由がここにしか書かれていない**ことがあるためです。
仕様書は「何を決めたか」を書きますが、章と開発日誌には
「なぜそう決めたか」「何を試して失敗したか」が残っています。

仕様と食い違ったときは、**`docs/` が正**です。ここは過去の記録であり、
現在の実装を説明するものではありません。
