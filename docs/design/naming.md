# 名前づけの規約と「改名手順」

> **この言語の名前は将来変わるかもしれません。**
> そのときに書き換える場所を、あらかじめ 3 か所に閉じ込めておくための取り決めです。

---

## 1. 原則

**言語名に依存する文字列は、コードに直接書かない。**

| 種類 | 例 | 名前に依存するか | どこで決まるか |
|---|---|---|---|
| 人が読む言語名 | `Polonium` | ✅ する | `LANG_NAME` |
| ソースの拡張子 | `.po` | ✅ する | `LANG_EXT` |
| コンパイラのコマンド名 | `poloniumc` | ✅ する | `LANG_CC` |
| C 側の内部マクロ接頭辞 | `PLC_LIB_DIR` | ❌ しない | 固定 |
| ランタイム関数の接頭辞 | `pl_str_len` | ❌ しない | 固定 |
| ディレクトリ構成 | `src/ selfhost/ lib/` | ❌ しない | 固定 |

**🤔 なぜ内部接頭辞を名前と切り離すのか**

`MYTHON_LIB_DIR` のような接頭辞は、言語名が変わるたびに
「環境変数名の変更 → ドキュメント → テストスクリプト」と波及します。
接頭辞を `PLC_`（**P**rogramming **L**anguage **C**ompiler）に固定しておけば、
改名しても**環境変数・ABI・リンク互換性は一切動きません**。
生成コードがリンクするランタイム関数（`pl_alloc` など）も同じ理由で `pl_` に固定です。

---

## 2. 名前が決まる 3 か所

| ファイル | 対象 | 内容 |
|---|---|---|
| `Makefile` の `LANG_NAME` / `LANG_EXT` / `LANG_CC` | ビルド | `-DPLC_LANG_*` として C 版に渡す。実行ファイル名も `build/$(LANG_CC)` |
| `src/langinfo.h` | C 版（stage0） | `-D` が無いときの既定値。コードは必ずこのマクロ経由で名前を使う |
| `selfhost/langinfo.po` | Polonium 版（stage1 以降） | 同じ値を関数で返す（Polonium にプリプロセッサが無いため） |

```
      Makefile ── -DPLC_LANG_NAME/EXT/CC ──▶ src/langinfo.h ──▶ C 版コンパイラ
                                             selfhost/langinfo.po ──▶ Polonium 版コンパイラ
                                                    ▲
                                                    └── 値は手で一致させる（下のテストで検証）
```

**⚠️ 2 つの langinfo は同じ値でなければなりません。**
ずれると stage0 と stage1 の出力（IR ヘッダの `; Generated by ...`）が食い違い、
`make selfhost-test` が落ちます。**つまりテストが自動で検出します。**

---

## 3. 改名の手順

1. `Makefile` の `LANG_NAME` / `LANG_EXT` / `LANG_CC` を書き換える
2. `src/langinfo.h` の既定値を同じ値にする
3. `selfhost/langinfo.po` の `NAME` / `EXT` / `CC` を同じ値にする
4. 拡張子を変えたなら、ソースファイルの名前を一括で変える
   ```bash
   find . -path ./.git -prune -o -name '*.po' -print | while read -r f; do
       mv "$f" "${f%.po}.<新しい拡張子>"
   done
   ```
5. 文書と comment の言語名を一括置換する（`docs/` `README.md` など）
6. `make clean && make test && make bootstrap` が通ることを確認する

**✅ 確認**：`make info` で現在の名前設定が表示されます。

```
$ make info
LANG_NAME    = Polonium
LANG_EXT     = .po
LANG_CC      = poloniumc
```
